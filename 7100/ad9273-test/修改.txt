目标文件：openimage.m (第 128-132 行)
修改动作：
不能再简单粗暴地用 typecast(..., 'int16')。因为 AD9273 是 12-bit，放在 16-bit 的内存格子里，必须手动用掩码（Mask）切掉高 4 位的“垃圾数据”，并将 Offset Binary（偏移二进制）还原为有符号数。

请将原来的 data = [...] 替换为以下严格的解码流程：

Matlab
% 1. 先将底层发上来的字节流当做【无符号 16 位 (uint16)】读取
raw_data1 = typecast(blob_u8(1,:), 'uint16');
raw_data2 = typecast(blob_u8(2,:), 'uint16');

% 2. 施加 12-bit 掩码 (0x0FFF = 4095)，强行滤除高 4 位的无效垃圾比特
valid_data1 = bitand(raw_data1, 4095); 
valid_data2 = bitand(raw_data2, 4095);

% 3. Offset Binary 解码：12-bit 的中值是 2048。减去中值使其变为有符号数
signed_data1 = double(valid_data1) - 2048;
signed_data2 = double(valid_data2) - 2048;

% 4. 重新组装为通道矩阵 (8 通道)
data = [
    reshape(signed_data1, 8, []);
    reshape(signed_data2, 8, []);
];

3. 时钟与 FPGA 降级 (极其重要的硬件防坑)
目标文件：word_deframer.v (FPGA) 与 硬件时钟板

FPGA 修改：提醒李政泽，必须把 word_deframer.v 第 59 行的 i_word_deframer_bit_sel 设置为 2'b00（代表 12-bit 模式）。

时钟降频（物理风险）：原来的 oi_rx.m 里 fs = 80 (80MHz)。但是 AD9273 的物理极限是 50MHz！ 如果你们的时钟板给它灌 80MHz 的时钟，芯片会直接死机或输出乱码。你们必须把时钟板的频率降到 40MHz 或 50MHz，并在 oi_rx.m 里将 fs 改为对应的值。

# 闸门调试指南

> 分支：`feature/gate-diagnostics`  
> 目的：不改检验逻辑，纯加诊断信息，帮助在实验中定位"有效帧推进困难"的原因

---

## 一、怎么看 qDebug 输出

闸门统计不显示在上位机界面上，而是输出到 **Qt Creator 的"应用程序输出"窗口**。

### 打开方式

1. 用 **Qt Creator** 打开 `BoneDensity.pro`
2. 点击左下角绿色三角形 **"运行"**（不要直接双击 exe）
3. 运行后，Qt Creator 底部会出现 **"应用程序输出"** 面板
4. 这个面板里能看到所有 `qDebug` 打印的内容

### 每轮结束时自动打印

每次小测量完成（成功或失败），控制台会自动输出一行完整统计：

```
闸门统计(87帧): BJump=0.0% Boundary=0.0% Diff=12.6% Dir=2.3%
CorrA=26.4% CorrB=8.0% AngDiff=35.6% AngGap=28.7%
StableWarmup=18.4% StableConc=11.5% StableLock=5.7%
```

## 二、每个参数的含义

### 检测流程：一帧数据要过 7 道闸门

```
原始波形 → [闸1: B跳变] → [闸2: 边界] → [闸3: AB差] → [闸4: 方向]
         → [闸5: 相关性] → [闸6: 角度] → [闸7: 稳定性] → 有效帧 ✓
```

任何一个闸门不过，这帧就被丢弃。

### 各闸门详解

| 简称 | 全名 | 判断条件 | 如果不过说明什么 |
|------|------|----------|-----------------|
| **BJump** | B通道波包跳变 | B的粗定位和精定位 lag 差距 ≤ 70 | 超声信号的首波识别不稳定，可能跳到了后面的波包。**通常不是操作问题，可能是探头硬件或噪声。** |
| **Boundary** | 边界反射 | 首波位置 < 260 点 | 信号太靠近采样窗口起始位置，疑似是边界反射而非真正的骨传导波。**探头位置不对，或骨质太薄。** |
| **Diff** | A/B通道lag差 | abs(A_lag - B_lag) ≤ 18 | A和B两路信号的到达时间差距太大。**探头倾斜严重，A/B对接触不对称。** |
| **Dir** | A/B方向检查 | A_lag - B_lag ≥ -2 | A通道的信号反而比B早到（正常B应该先到）。**探头角度异常，大概率是侧偏了。** |
| **CorrA** | A通道相关性 | 互相关系数 ≥ 0.78 | A通道（AD→AC）两个接收器的波形相似度不够高。**耦合剂不足、探头没贴紧皮肤、或该位置骨骼信号弱。** |
| **CorrB** | B通道相关性 | 互相关系数 ≥ 0.55 | B通道（BD→BC）同上。注意B的门槛比A低（0.55 vs 0.78），因为桡骨上B本身波动大。 |
| **AngDiff** | D值（角度延迟差） | A_lag - B_lag 在 [7.0, 13.0] 范围内 | 探头相对于桡骨的角度不对。D值代表探头倾角——D太小说明探头太立，D太大说明太躺。 |
| **AngGap** | G值（A/B中心差） | pairMidGap 在 [-4.0, 4.0] 范围内 | 探头在桡骨上的左右位置不对。G值为正说明偏左侧，为负说明偏右侧。 |
| **StableWarmup** | 预热中 | 还没攒够 22 帧候选lag | 刚开检测，系统在收集波形建立稳定基准。**这不是问题，保持不动等几秒就好。** |
| **StableConc** | 簇不够集中 | 30帧候选里不到15帧落在 ±4 点内 | lagB波动太大，无法锁定一个稳定值。**手晃了、耦合剂干了、或骨骼本身不均匀。** |
| **StableLock** | 偏离锁定簇 | 连续8帧超出锁定范围 | 之前已经锁定了稳定lag区间，现在又跑偏了。**探头位置变了，请回到之前的触压角度。** |

### 界面上的 D 和 G

界面上中间区域有两个竖条进度条：

- **左竖条（D）**：显示 `lagA - lagB`，目标是 9.0。偏离目标时竖条会偏绿或偏红，代表倾角不对。
- **右竖条（G）**：显示 `pairMidGap`，目标是 0.0。偏离时代表探头左右位置不对。

有效值进度条下面的**橙色文字**会告诉你该怎么调（如"探头偏左，请向右轻移"）。

## 三、快速诊断方法

在控制台输出里，**找百分比最高的那一项**：

| 最高的项 | 问题是什么 | 怎么办 |
|----------|-----------|--------|
| **AngDiff > 30%** | D值频繁越界（倾角不对） | 调整探头倾角：数值偏小就放平一点，偏大就立起一点 |
| **AngGap > 30%** | G值频繁越界（左右位置不对） | 调整探头左右位置：正值偏左就向右移，负值偏右就向左移 |
| **StableWarmup > 30%** | 预热太久（一直建立不了稳定基准） | 减小手部晃动，确保探头稳定贴在同一个位置 |
| **StableConc > 15%** | lagB波动大（稳定不下来） | 补耦合剂，减小手晃 |
| **StableLock > 20%** | 锁定后频繁脱锁 | 探头位置变了，回到最初锁定的那个角度 |
| **CorrA > 30%** | A通道相关性差 | 补耦合剂，探头贴紧皮肤 |
| **CorrB > 20%** | B通道相关性差 | 同上 |
| **BJump > 5%** | 波包跳变 | 检查探头硬件，或换个测量位置 |
| **Diff > 15%** | A/B差异大 | 探头倾斜严重，重新摆放 |

### 组合判断

```
Ang 高 + Stab 低 → 还没找到正确角度，继续调整探头位置
Ang 低 + Stab 高 → 角度对了但手晃，减小晃动
Ang 高 + Stab 高 → 角度完全不对，重新定位
Ang 低 + Stab 低 + Corr 高 → 角度对、稳定、但信号差，换个位置测
```

## 四、实验步骤

### 步骤 1：标定物基准测试

先用**铜块**或**塑料标定块**跑一轮：

- 铜块上 `AngDiff` 和 `AngGap` 应该很低（<10%），因为标定物没有角度问题
- 记录标定物的 SOS 值

> 如果铜块上 Angl 就很高，说明探头硬件或首波检测有问题。

### 步骤 2：人体测试

1. 找角度：先花 30 秒挪探头，找到进度条能推进的位置
2. 保持不动：让系统采集完整一轮（30 帧）
3. 看控制台输出：记下各闸门百分比

### 步骤 3：故意偏一点

故意把探头偏一点，观察哪些百分比飙升，确认诊断逻辑正确。

## 五、调参决策表

> **每次只改一个参数，改完先用铜块验证。**

| 观察 | 调哪个参数 |
|------|-----------|
| `StableWarmup > 30%` | `stableLagWarmupCount` 22→14 |
| `StableConc > 15%` | `stableLagTolerance` ±4→±6 |
| `StableLock > 20%` | `boneLagUnlockCount` 8→12 |
| `AngGap > 30%` | `anglePairMidGapMin/Max` [-4,4]→[-6,6] |
| `AngDiff > 30%` | `angleSignedDiffMin/Max` [7,13]→[5,15] |
| `CorrA > 30%` | `frameCorrAMin` 0.78→0.70 |
| `CorrB > 20%` | `frameCorrBMin` 0.55→0.45 |
| `BJump > 5%` | 先检查硬件和耦合，不是参数问题 |

## 六、回归验证

任何参数修改后：

1. **铜块测试** — SOS 应与修改前一致（偏差 < 20 m/s）
2. **同一受试者同一位置** — SOS 应在修改前 ±30 m/s 内
3. **确认有效帧推进速度** — 是否比修改前更快

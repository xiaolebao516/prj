## 使用和版本规则

1. **以日志记录的温度为准取对应表行**，区分“日志中录入温度”与“独立温度计确认的实际材料温度”。例如这次 2026-10-26 三份日志都录入了 23°C，分别对应 KSGR-3=2310、KJMK-02=2711、KSGR-2=4729 m/s。
2. 对不在表中、带小数的温度保留原值。**本表不预先规定插值方式**；离线分析确需插值时须明确记载方法及参考值来源，不能将插值结果伪称证书原值。
3. 旧版 JSONL 不补写 `temperature_C` 或材料 ID；只在单独的离线映射表里记录来自实验记录/操作者的可核实补充信息，未知保留未知。
4. 本表**不是校准程序的配置文件**；不能因三个测量点拟合成功就认定已通过计量校准。KSGR-2、KSGR-3 各有证书 2%（k=2）的不确定度，KJMK-02 不确定度未知。
5. 后续以本仓库这个路径的**已提交版本**为参考数据单一入口；需更新时根据新的证书/照片做明确变更并保留 Git 历史。避免在临时聊天中维护互相矛盾的表。

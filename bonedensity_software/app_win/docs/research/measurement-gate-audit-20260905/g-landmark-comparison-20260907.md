# G取点跳变：原因与两种离线对照

## 结论

已有记录足以证明一处G跳变由相对谷深门槛触发，不需要用户重新测量来复现。两种有限的诊断改法尚不足以支持部署：降低门槛只有局部收益；简单保持上次波谷反而使两轮不能在原记录结束前完成。没有改动产品算法、进度条或试测程序。

## 对照设计

共19份原记录：新双段版10份、最初版8份、observe版失败记录1份。原始AD/AC重建4715个采用谷值分支的帧；30%对照的早端选点逐帧匹配日志。保留原滤波、绝对谷深、相邻谷合并和宽搜索失败后的起点附近搜索分支。最初诊断工具漏掉后者，在第19份记录校验失败；补齐实际已有分支后全部通过，这不是产品修复。

预先限定两个研究候选，不以G接近0或SOS接近3900选择候选：

- `quarter`：AD相对谷深30%改为25%，其他搜索规则保留。
- `tracked`：允许25%谷深，用B特征中点移动量预测上次AD波谷位置，附近20点内优先维持，否则回退原30%规则；连续10个不适用帧清除记忆。

均按候选AD早点和原B lag附近寻找AC晚点。只在晚点有效、原A lag处的局部双窗口最小相关性至少0.78时替换G，否则保留原G。实际回放保持原日志的A/B评分、A/B lag、SOS、D、G±6、稳定性规则及各版本观察顺序。这是隔离的G特征敏感性研究，不是将全套A检测器改成25%的端到端候选。

候选G来自原始波形重建，后续使用实际产品稳定性和轮聚合代码进行特征回放。19份原配置对照均核对日志判定、状态及轮结果；候选尚未实现到产品原始处理通路，更未进行硬件验证。

# 优先推进有效值：当前双段评分下的G范围比较

## 用户目标与参考

用户再次明确首要问题是有效值迟迟不推进。样机只有最终SOS，但用户报告多次测得约3800–3900，可作为当前经验参考；不要求其提供样机过程或同一套上位机，也不再把重新测样机作为本轮离线分析前提。参考区间不进入候选算法或样本筛选，不等同逐帧配对真值。

本轮只研究减轻现有姿态门槛造成的停顿，暂不修改B路SOS、滞后估计、A评分、D、稳定性窗口、丢弃规则、串口或进度条。

## 比较与验证

19份完整日志都先验证原记录配置。10份新日志直接使用当前双段A0.78版本；9份旧日志用先前原始波形已验证的双段A0.78评分和observe-before-G顺序，重放当前版本作为对照。其结果与先前 `dual-window-078-implemented-results.json` 的 `dual_window_078` 完全一致。不能把旧日志记录的原算法与本轮当前算法混为一谈。

先比较四种有限研究配置：当前G±6、G±10、25%谷深修正G/±6、修正G/±10。发现±10有进度收益但也新增低样本后，增加一个此前研究过、在当前评分组合下尚未比较的保守±8对照。没有继续遍历参数寻找接近参考的最优值。

G±8、±10均使用实际产品原始波形处理代码重放全部19份记录，并与独立特征回放的完成时刻、首次有效值、丢弃计数和轮结果逐份一致；没有改动产品源码或已部署EXE。修正G的两组仍只是原始波形重建G后输入实际稳定性/聚合代码的研究对照，不是产品原始处理通路中的候选实现。

摘要检查每份接受轨迹长度=30+丢弃数；最后30个未丢弃值按实际截尾方式重建轮结果。这里的30值仍包括随后参与每轮截尾的两端样本，不代表全部30值进入最终18值均值。19份记录、5种配置均完成且通过原有轮质量检查；这不是准确性通过。

### 其他记录与风险

- 最新第二组：累计48.822→46.302秒（±8），只改善约2.52秒。第三轮较早接受的额外样本随后丢弃，丢弃总数8→15；不能把这部分早计数称为持续推进改善。
- 最新10轮：±8相对当前版本的单轮结果最大绝对变化约16.49m/s。第二组3664.35→3662.83、3967.68→3971.25，原有轮间偏差未解决。
- 8份旧记录按当前双段版重放：累计91.797→86.227秒；最早一轮首次计数34.181→20.030秒，但这些前段样本后来被丢弃，最后30值从47.517秒才开始。因此最终完成只从54.922→52.005秒。单轮结果最大变化约30.96m/s。
- 旧171秒失败轨迹按当前双段版已能在81.933秒完成；±8仅缩至81.371秒，首次计数仍77.711秒。本候选不解决该段长等待。
- ±8与±10都新增了约3550.72的单次有效样本，位于原本偏低的第二组第1轮；不能宣称±8消除了±10的新低样本风险。该值不是最终报告SOS，轮结果变化小也不能证明它是正确样本。
- 修正谷深再配±10，相对仅±10，第一组累计只再缩短0.281秒，丢弃却1→3，其他组无收益；不建议同时修改G特征提取。

## 推荐的下一步：独立±8试用版，尚未获部署批准

这不是已经解决准确性的问题，而是有固定轨迹进度收益、改动小且可回退的实验候选。建议先用±8，不直接用±10或叠加谷深改法。

待确认的精确改动：

1. 在当前独立双段A0.78/observe-before-G试测版基础上，仅将G通过范围由[-6,+6]改为[-8,+8]；帧和轮检查使用同一范围。
2. 保持SOS公式、B取点、A评分、D范围、稳定性/清空机制、30值一轮/五轮流程和原进度条几何/映射不变；中线仍是操作目标，不把绿色区域当新目标。
3. 新的独立实验宏/标题/日志配置和独立输出目录，保留当前±6版与患者数据，不复制临床XML，不自动运行桌面或设备。
4. 测试先覆盖G6/8边界、G8以外拒绝、A/B/D不通过仍拒绝、持续失锁仍清空，以及默认版本不变；实际新程序原始波形回放应逐份匹配本研究±8结果，再做固定工具链隔离部署。
5. 先由用户自己正常测量，比较起步和持续进度、单轮结果及重复性。明确保留低轮/失败日志；不得只展示最终五轮均值。若结果偏离扩大或推进无帮助，保留回退并继续定位，不当作验收成功。

这个建议需要对上述具体G阈值和独立试用版的确认，先前“继续分析”的授权不等于已批准部署。

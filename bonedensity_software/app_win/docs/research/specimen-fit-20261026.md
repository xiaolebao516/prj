## 候选模型比较

令 `x` 为设备记录的原始 B SOS（m/s），`y` 为修正后的 SOS（m/s）；三组训练点：`(2450,2310)`、`(2800,2711)`、`(4711.5384615,4729)`。

| 模型 | 拟合方式 | 三个中位数的最大绝对相对残差 |
|---|---|---:|
| 比例 `y=a*x`（等效 D-only） | 三点最小二乘 | 4.56% |
| 固定 SOS 偏移 `y=x+b` | 三点最小二乘 | 3.01% |
| **SOS 仿射 `y=a*x+b`** | 三点最小绝对 SOS 平方误差 | **0.565%** |
| **SOS 仿射 `y=a*x+b`** | 三点最小化**最大相对误差** | **0.494%** |
| 时间基准仿射 `1/y=p/x+q` | 三点最小二乘倒数值 | 1.06% |
| 单独固定 lag/time 偏移 | 三点最小 SOS 平方误差 | 5.55% |
| 三参数二次 `y=a*x²+b*x+c` | 用三点解三个参数 | 训练残差恰好 0，但不能说明可信 |

**推荐暂作离线候选的模型：三点最小最大相对误差仿射模型**：

```text
SOS_corrected = 1.07490541 * SOS_raw - 312.11634  [m/s]
```

该模型的三点拟合中位数分别为：KSGR-3 **2321.40**（+0.494%）、KJMK-02 **2697.62**（-0.494%）、KSGR-2 **4752.34**（+0.494%）。这给三个参考点同等的**相对误差上限**；参数仅适用于离线分析，没有设备激活意义。

若按通常最小二乘拟合 `SOS_corrected = 1.06494864 * SOS_raw - 286.17561`，三点的拟合结果为：2322.95（+0.561%）、2695.68（-0.565%）、4731.37（+0.050%）。两者差距不大，说明目前无必要仅为了再压低训练残差而立刻采用三参数模型。

## 不能直接写回设备的原因

1. **三个材料均已参与拟合，并非独立验证。** 将两个材料拟合后预测第三个材料的 SOS 仿射模型，三轮留一预测误差为：KSGR-3 +1.36%，KJMK-02 -0.98%，KSGR-2 **+3.64%**。模型在低/中声速两个点拟合后向高端外推仍有明显风险。
2. **并不是每一帧都在 ±1%。** 对上面的最小最大相对误差仿射模型，全部 `B.valid` 帧落入本材料参考值 ±1% 的比例为 KSGR-3 **98.7%**、KJMK-02 **57.6%**、KSGR-2 **94.9%**；此外 KSGR-2 的 B 无效帧占 43.0%。模型修正最终数值无法消除选峰或采集失败。
3. **证书测量不确定度影响准确度结论。** KSGR-2 和 KSGR-3 证书注明声速不确定度 2%（k=2），KJMK-02 标签未给不确定度；不能用三点训练拟合时小于 1% 的残差，声称仪器已取得小于 1% 的绝对准确度。
4. `D=7.84 mm` 仍按用户已确认的探头型号几何参数保留；SOS 仿射模型的斜率/截距不代表真实 D 改变，也不能自动解释通道时基、相位或互相关选峰偏差。
5. 复杂模型如二次多项式、三参数有理函数都能让三组**训练中位数**精确等于参考值，但三个参数对三个点恰好插值，缺乏独立证据，不推荐部署。

## 结论和下一验证

当前三次 23°C 新日志表明：**存在一个两参数 SOS 仿射离线候选，可把三块试块的训练中位数都压进 ±0.5% 区间**；但 KJMK-02 帧间漂移及 KSGR-2 无效率尚未解决，无法称为已通过校准。建议保持当前正式处理参数不动，完成重新放置/重新耦合、多轮独立验证，用本报告冻结的候选参数预测新采集轮次，而不是在新数据上继续重拟合。同时做同帧原始波形的相位、选峰和校准路径/患者路径一致性审计。

**复核边界**：以上是对用户提供 JSONL 中既有 B.lag/B.sos 的 Python 离线计算；未在 Windows Qt 上运行编译或单元测试，未通过 GitHub CI，也不是实机独立验收。

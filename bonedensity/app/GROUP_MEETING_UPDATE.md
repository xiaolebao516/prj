# 超声骨密度仪上位机更新汇报

## 先说结论

本次没有改动骨密度计算、检测门限或硬件通信规则，主要把软件从“能完成检测”完善到“更方便多人使用、结果更容易保存和追溯、异常时更容易恢复”。

## 一、功能更新

### 1. 增加本地账号管理

**做了什么：** 软件现在有管理员账号 `admin`，默认密码为 `1`。管理员可以创建、停用、重置和删除普通账号；普通账号只能使用软件，不能管理账号。

**为什么：** 以前账号密码写在程序里，所有人只能共用一个账号，也不能管理使用人员。

**现在的效果：** 账号会保存在本机，软件重启后仍然可用；实验室多人使用时更清楚。

### 2. 支持同一患者保存多次检测

**做了什么：** 患者基本资料和检测结果分开保存。同一患者每次完成检测并点击“保存结果”后，都会增加一条新的历史记录，不再覆盖以前的结果。

**为什么：** 以前患者资料和结果混在一起，同一患者第二次保存结果时，第一次结果可能被覆盖。

**现在的效果：** 可以查看某位患者历次检测的时间、SOS、T 值、Z 值和诊断结果，也可以删除一条误保存的记录。删除患者时，会同时删除该患者的历史记录，避免留下无归属数据。

### 3. 明确“选患者”和“开始检测”的顺序

**做了什么：** 把原来容易混淆的按钮职责拆开：患者按钮只负责建立或更换患者，检测按钮只负责开始或停止检测。

**为什么：** 以前一个按钮同时负责选患者和开始检测，容易出现没有选患者就测量，或测量中切换患者的情况。

**现在的效果：** 未选患者不能开始检测；检测中不能更换患者；更换患者后会清空未完成进度和临时数据，但不会删除已经保存的历史结果。未保存结果切换患者前会要求确认。

### 4. 整理患者资料页面

**做了什么：** 患者资料页只保留姓名、编号、性别、出生日期、身高、体重等基础信息。检查日期和诊断等检测结果不再在患者资料页手动填写；患者编号在详情页只读。

**为什么：** 这些检测结果字段已经不属于患者基本资料。以前用户可以修改它们，但实际保存后可能不会长期保留，容易产生误解。

**现在的效果：** 页面上能编辑的内容都会被真正保存；检测结果统一从历史记录中查看；患者编号不会被误改，从而保证历史记录仍对应正确患者。

## 二、问题修复

### 1. 修复 USB 意外拔出后反复弹窗或闪退

**问题：** 连接设备后直接拔掉 USB，软件可能持续弹窗，个别情况下会异常退出。

**处理：** 设备异常断开时，软件只处理一次，停止采集、清理未完成数据并回到未连接状态。

**效果：** 拔掉 USB 后软件不应继续反复提示；重新插入设备后可以再次连接。

### 2. 修复账号文件异常后无法登录

**问题：** 如果本地账号文件内容损坏，软件可能无法找到一个可用管理员账号，导致无法登录。

**处理：** 软件会检查管理员账号是否完整可用。发现账号内容异常时，会先备份原文件，再恢复默认管理员 `admin / 1`。

**效果：** 账号文件异常后不会轻易把软件“锁死”；原异常文件仍会保留，便于后续检查。

### 3. 修复特殊字符混入账号文件时未被识别的问题

**问题：** 某些明显不合法的账号内容以前可能被系统忽略，从而被误认为正常。

**处理：** 现在会严格检查账号关键内容是否有效；只要发现不合法，就按异常账号文件处理并恢复默认管理员。

**效果：** 账号恢复判断更可靠，减少表面正常、实际无法登录的情况。

### 4. 修复 Qt 编译后“找不到入口点”无法启动的问题

**问题：** 编译完成后启动程序时，出现“无法找到入口点”的 Windows 弹窗。

**原因：** 电脑上同时存在两套 C++ 编译环境，编译时和运行时使用的版本不一致。

**处理：** 已统一使用 Qt 自带的编译环境重新构建对应程序。

**效果：** 程序已能正常启动。后续在 Qt Creator 中需要继续使用 Qt 6.5.3 对应的 MinGW 编译套件。

## 三、已完成检查与仍需验证项目

**已完成：** 已多次完成 Debug 重新编译；账号异常恢复、正常账号保留、患者资料保存、历史记录保存等基础流程已进行程序测试；Qt 启动错误已通过重新构建和隔离启动检查确认消失。

**仍需实验室验证：** 真实探头检测、USB 热拔插、完整人工点击流程，以及多次真实测量后的历史记录展示。

## 一句话总结

这次更新让软件更适合实际使用：人员使用有账号、患者结果能追溯、操作顺序更清楚、异常情况更容易恢复。

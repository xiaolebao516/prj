# 门控诊断调试指南

> 分支：`feature/gate-diagnostics`  
> 目的：不改任何检验逻辑，纯加诊断信息，用于在人体实验中定位"有效帧推进困难"的根因

---

## 一、准备工作

1. 切换到诊断分支：
   ```bash
   git checkout feature/gate-diagnostics
   ```

2. 编译运行（用 Qt Creator 打开 `BoneDensity.pro`，或命令行 `qmake && mingw32-make`）

3. 连接设备，进入**病人检测模式**

---

## 二、UI 上观察什么

### 帧被拒时（红色文字）

界面上 `lblProcessStatus` 标签在被拒帧到达时会显示三行信息：

```
未累计：D=6.5∉[7.0,13.0], 预热中(12/22)
→ D偏小：探头倾角偏高，请稍微放平探头
统计(30帧): BJump0% Diff13% Corr27% Ang53% Stab40%
```

| 行 | 含义 |
|----|------|
| 第一行 | 哪些闸门拒了这帧（D=角度差, G=中心差），括号里是预热进度 |
| 第二行 | 操作建议 |
| 第三行 | 累计 10 帧后出现，显示各大类闸门的拒绝率百分比 |

### 帧被接受时（绿色文字）

```
姿态有效：Gap=1.2，目标=0.0，lagA-lagB=9，进度 12/30
```

进度条推进、计数增加。

---

## 三、如何判断问题出在哪

### 方法：观察统计行（第三行）的百分比

找**百分比最高的那一项**：

| 最高项 | 含义 | 说明 |
|--------|------|------|
| **Ang 高**（>40%） | 探头角度频繁越界 | 操作者的探头角度不稳，或当前受试者的骨骼形状与标定窗口不匹配 |
| **Stab 高**（>40%） | 稳定性不足 | 手部晃动太大，或 lagB 波动大 |
| **Corr 高**（>20%） | 信号相关性不足 | 耦合剂不够、探头没贴紧、或该位置骨质信号弱 |
| **Diff 高**（>15%） | A/B lag 差异过大 | 可能探头倾斜严重，或 A/B 对探头接触不对称 |
| **BJump 高**（>5%） | 波包跳变 | 首波检测不稳定，可能是噪声干扰 |

### 判断逻辑

```
Ang 高 + Stab 低 → 操作者还没找到正确角度，需要调整探头位置
Ang 低 + Stab 高 → 角度对了但手晃，需要依靠支撑/减小晃动
Ang 高 + Stab 高 → 探头根本没对准，需要重新定位
Ang 低 + Stab 低 + Corr 高 → 这是最坏的情况：角度对、稳定、但信号差，可能需要换个测量位置
```

## 四、实验步骤

### 步骤 1：标定物基准测试

先用**铜块**或**塑料标定块**跑一轮：

1. 观察第三行统计 —— 铜块上应该 Ang% 很低（<10%），Stab% 也很低
2. 记录标定物的 SOS 值作为基准

> **预期**：铜块上所有拒绝率应 <15%。如果铜块上 Ang% 就很高，说明探头硬件或首波检测有问题，不是参数的问题。

### 步骤 2：人体测试（找最佳位置）

在受试者桡骨上：

1. 先花 30 秒找到进度条能推进的角度（接受帧出现绿字）
2. 然后**保持不动**，让系统采集完整一轮（30 帧）
3. 记录这一轮结束时的统计行数据

### 步骤 3：人体测试（故意偏离）

故意把探头偏一点（模拟不熟练操作者）：

1. 观察统计行变化 —— 哪个百分比飙升？
2. 观察指引文字 —— 提示是否正确？

### 步骤 4：重复 3~5 轮

在同一个受试者同一个位置：
- 记录每轮的 SOS 值
- 记录每轮的拒绝率统计

## 五、控制台日志

每轮结束时 `qDebug` 会输出完整统计：

```
闸门统计(87帧): BJump=0.0% Boundary=0.0% Diff=12.6% Dir=2.3%
CorrA=26.4% CorrB=8.0% AngDiff=35.6% AngGap=28.7%
StableWarmup=18.4% StableConc=11.5% StableLock=5.7%
```

这个比 UI 上的更细 —— 可以看到是 CorrA 低还是 CorrB 低，是预热卡还是锁定卡。

---

## 六、调参决策表

拿到数据后，按以下规则决定调哪个参数：

| 观察 | 调哪个参数 |
|------|-----------|
| `StableWarmup > 30%` | `stableLagWarmupCount`（22→14） |
| `StableConc > 15%` | `stableLagTolerance`（±4→±6） |
| `StableLock > 20%` | `boneLagUnlockCount`（8→12） |
| `AngGap > 30%` | `anglePairMidGapMin/Max`（[-4,4]→[-6,6]） |
| `AngDiff > 30%` | `angleSignedDiffMin/Max`（[7,13]→[5,15]） |
| `CorrA > 30%` | `frameCorrAMin`（0.78→0.70） |
| `CorrB > 20%` | `frameCorrBMin`（0.55→0.45） |
| `BJump > 5%` | 先检查硬件和耦合，不是参数问题 |

**每次只改一个参数，改完回步骤 1 验证铜块不受影响。**

---

## 七、回归验证

任何参数修改后：

1. **铜块测试** —— SOS 应与修改前一致（偏差 < 20 m/s）
2. **同一受试者同一位置** —— SOS 应在修改前 ±30 m/s 内
3. **确认有效帧推进速度** —— 是否比修改前快

如果铜块或同一位置的结果发生显著偏移，说明该参数修改影响了精度，应回滚。

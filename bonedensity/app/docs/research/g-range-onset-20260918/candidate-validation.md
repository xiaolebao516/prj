## 已完成工作

对同一101份原始记录、22847帧重新读取四通道波形；原始B/A特征及计数/轮次基线匹配。原始97轮中，首波40点检查排除9月14日的3个极低轮次，比较基线共94轮。各文件沿用实际A/G等配置，不像前一份G面板统一替换为[-12,0]。所有候选始终保留原始首波40点保护，改变后的B定位也不能绕过40点保护。

先固定四种独立候选，再计算结果：

1. **first_hit**：B的定位采用连续越阈值第一点；A算法不改。
2. **ratio30**：B的包络回溯比例从0.20改0.30；A算法不改。
3. **edge5**：仅当最大相关值位于局部边界时，朝该边扩展最多5点，仍在原物理范围内；保留原相关平台选点。
4. **local_peak**：B在原局部范围内直接选最高正相关，取消B相关平台上的经验选点；不放大搜索范围。

每种都重新计算候选B、依赖B的A搜索、A双窗口相关、D、G、稳定计数和单轮统计。不是只替换最终声速。候选没有改变A/G/D门限来让回放通过。

## 为什么只看声速会误判

对最新原751个有效帧，逐帧比较同一输入下候选门控（下列失败类别可重叠，未包含稳定状态）：

| 候选 | 仍过全部预检查 | G失败 | D失败 |
|---|---:|---:|---:|
| first_hit | 706 | 45 | 0 |
| ratio30 | 97 | 642 | 58 |
| edge5 | 632 | 0 | 119 |
| local_peak | 466 | 0 | 285 |

这些751帧中未新增A/B相关性、边界或方向预检查失败；主要损失来自D/G定义与定位/延迟的耦合。完整状态回放另见上表，不能用本表预检查数量直接推算轮次数。

**具体例子一：改变首波定义会改变G，即使原始数据完全相同。**

文件`round-20260915-090806-580-0cbf3cff-7d74-468d-a48b-9b2f9b1ebf7f.jsonl`，sequence2204：

- 原来：SOS3656.72，B延迟134，A延迟142，D8，G=-1.5。
- ratio30：SOS3684.21，B延迟133，A延迟142，D9，G=20，无法计入。

不能把“声速提高约27”说成改好了。G改变来自同一波形的计算地标变化，不是这帧发生了探头移动。G是B两首波位置中点与A两特征位置中点之差，并非独立测得的倾角。这也解释了为什么不能在改变定位定义后，未经验证沿用或随意放宽G。

**具体例子二：扩大搜索范围会改变D，且可能让原来较高结果降低。**

文件`round-20260915-091248-514-9321a973-7acc-416b-8620-a51105fd2c94.jsonl`，sequence20：

- 原来：SOS3858.27，B延迟127，A延迟134，D7，G=-11。
- edge5：SOS3769.23，B延迟130，A延迟134，D4，无法计入。

所以不是把搜索边界扩大一点就一定更接近参考值。

## 已知延迟控制：经验选点会引入偏移

构造一个高斯包络正弦波，将它原样平移已知整数点数，得到没有噪声、没有幅度或形状差异的两路信号。在7种真延迟和3种粗定位误差(-2/0/+2)上测试当前相关细化函数，共21例。

| 已知真实延迟 | 当前平台选点 | 原范围内最大相关选点 |
|---:|---:|---:|
| 100 | 97 | 100 |
| 110 | 107 | 110 |
| 128 | 126 | 128 |
| 135 | 134 | 135 |
| 160 | 160 | 160 |
| 200 | 202 | 200 |
| 250 | 252 | 250 |

每个真延迟下，三种粗定位误差输出相同。128点的理想输入被选成126点，按本批距离/周期，相当于3828.12变成3888.89。现有算法代码明确按相关峰延迟，从平台前部逐渐过渡到后部，含对材料速度的经验补偿；它不是无偏的“找真实延迟”估计器。

这是一项可复现的软件特性，**不能据此断言真实波形中的最高相关峰就是正确传播时间**。实测通道波形会变形，且local_peak在新记录仅保留4/25轮，因此不能仅凭合成测试替换生产算法。该特性也不能解释所有偏低值：本例偏差方向恰好使声速偏高。

## 判断与下一步边界

四个简单替换均未达到可部署条件，当前代码与A0.78/G[-12,0]等参数保留。分析不需要知道哪一帧发生重放，因此已有记录足够排除上述方案，不要求重复采集。

后续若继续设计候选，应把三个问题分别定义清楚再联合验证：

1. 哪个波形地标负责定位首波；
2. 哪个延迟估计代表两路信号的匹配时间，经验补偿是否另行标定；
3. A/B/D/G使用哪些一致的定义，不能为了保留计数而绕过不一致。

现有记录可以继续用于算法保留率、选点一致性及回归验证；它们没有同期真实传播时间标签，无法单独确认3736或3850哪一个正确。没有验证通过的候选前，不要求用户新增“不动/重放”测量。后续确需操作标签时必须先提供与日志对应的标记方法，而不是从数值突变猜测。

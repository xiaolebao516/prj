## 使用规则

1. 自动采集日志只保存材料 ID、材料名称和温度计实测温度，不在采集时自动写入参考 SOS。
2. 离线分析必须同时保留日志中的实测温度与所采用的证书温度点；若温度不在证书表中，不自行插值。
3. KSGR-2 与 KSGR-3 证书的不确定度为 2%（k=2），因此单靠它们不能证明设备绝对误差达到 1%。
4. 这张表不是自动温度补偿曲线，也不授权调整 D、bias、选峰或患者有效值筛选。

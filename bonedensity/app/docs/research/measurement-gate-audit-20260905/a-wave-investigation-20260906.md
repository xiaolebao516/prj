# A通道原始波形调查：为什么两个条达标仍不推进

## 问题与范围

用户批准基于已有记录继续调查，不批准直接改测量算法或门槛。本轮检查之前八份记录及新增零进度记录，共3692帧；其中3164个完整门控、A波谷分支帧（旧1667、新1497）实际重算取点、时差、SOS和相关性，与日志在1e-8容差内一致。另21个完整门控帧走备用分支，本轮没有纳入波谷窗口比较；更早退出的帧也不在该比较内。

使用固定Qt/MinGW的独立控制台工具链接现有 `src/signalprocessor.cpp`，不运行主程序、不连接硬件。研究代码 `a_wave_audit.cpp` / `.pro`；输出 `a-wave-results.json` 含九份输入SHA-256及逐帧诊断。未把新的试测日志冒充旧流程回放：这里只验证共同的A特征处理，不声称验证全流程、最终轮数或准确性。

## 关键发现

### 1. 主要不是“选了相关性次高点”

原逻辑并非总取最高相关性对应的时差。本轮在原取点和原窗口内扫描同一时差范围，核对实际选中分数与最大分数。

新记录中仅A相关性失败、其余前置条件通过的598帧，有596帧属于本轮重算的波谷分支。596帧中位分数0.625；即使改看原窗口的最大分数，也只有1帧达到0.78。由此排除“只换最高分点即可解决这次卡住”作为主要解释，不能因此改动测量时差。

### 2. 前段相似，后段差异明显

预先固定以下诊断区间，均以现有AD波谷为零点，不挑每帧最有利的窗口。原区间[-20,+90]共111点；前段[-20,+30]51点；中段[0,+60]61点；后段[+40,+90]51点；较长区间[-20,+140]161点。主要比较保持原时差不变，避免把换时差的收益混入窗口比较。

| 同一时差下的相关性中位数 | 旧记录已接受帧（251） | 新记录仅A失败帧（596） |
| --- | ---: | ---: |
| 原111点区间 | 0.807 | 0.625 |
| 前段51点 | 0.960 | 0.934 |
| 中段61点 | 0.885 | 0.749 |
| 后段51点 | 0.805 | 0.541 |
| 较长161点区间 | 0.823 | 0.261 |

可确认的是：现有A评分确实对所含的后段波形敏感，不是只有一团无可辨认的信号。新仅A失败组的后段/前段幅度RMS比，中位数AD约1.269、AC约0.360；旧已接受组分别约1.208、0.516，提示两路波形的幅度包络关系存在差异。相关性对整段统一倍数缩放不敏感，因此不能简单归因于“AC整体振幅小”；分段相对幅度、形状和相位关系都可能影响分数。

这不是确定的物理成因。没有证明差异来自耦合、组织、反射、探头或硬件故障，也没有证明后段信息应当被忽略。

### 3. 暂未发现大范围明显错取早到点，但不能证明取点正确

AD现有波谷与独立重算的包络到达点，在新仅A失败组的差值中位数为0采样点，旧已接受组为1点；两组均没有AD波谷贴近620/1300搜索边缘的情况。相应区间原始AD/AC样本没有0或4095及以上的触顶值。

这些检查不支持把本次大部分失败直接归因于AD取到遥远位置、卡搜索边缘或该局部区间饱和。两种取点算法也不是已知真值，少数异常点、AC配对错误及共同偏差尚不能排除。

### 4. 直接缩窗有明确风险，不能当成已验证方案

保持原时差，只把A分数改用前段51点，596个新仅A失败帧都会超过原0.78门槛。但它们的B候选SOS范围约3577–3984 m/s；旧记录也会新增479个前置机会，范围约3657–4495 m/s，包括4414、4495等高候选。

这些数值没有配对真值，不能称为已证明错误或已证明正确。这里只说明短窗高分不能保证用户要求的窄误差，且“新增前置机会”不等于最终接受或完成一轮。

同样不能为了提高分数顺手换时差：新仅A失败组若改用前段最高分的时差，308/596帧与原A时差相差至少3采样点，47帧会使原本通过的D超出原范围。窗口改变不仅影响质量分数，还可能影响姿态指标。不能直接沿用旧D标定解释。

## 当前结论和下一步

本次从“哪个门槛阻塞”推进到“哪个波形区间在降低评分”：A前段通常可匹配，但后段一致性变差；原长窗口评分把两者合成一个硬门槛。没有发现足以直接修复、并保证窄误差的单一代码错误，也没有得到可以放心部署的新参数。

后续可研究将首波匹配可信度与后段形状差异分开评估，并检查相邻窗口/连续帧的时差一致性、候选歧义和稳定B簇，避免只靠短窗高分放行。先用所有现有轨迹对照，包括新增高候选和仍失败的片段，再提出具体实验变更。不能用“靠近回忆中的3926”筛选算法；最终准确性仍需同期对照，现有数据无法证明某一类候选应被全部接收。

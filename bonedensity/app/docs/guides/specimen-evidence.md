# 试块实验波形记录（研发）

该功能仅保存诊断证据，不修改 SOS、相关峰搜索、校准阈值或 80 ms 采集流程。也不表示对任何试块完成了计量校准。

## 自动采集

1. 连接骨密度仪，在顶部“记录：关闭”选择具体材料：KSGR-2 紫铜桡骨体模（226GM13）、KSGR-3 聚苯乙烯桡骨体模（226GM14）、科进 KJMK-02（M2607289），也可选“其他塑料试块（型号未确认）”或自定义名称。新选项将 KSGR-2 标为原“铜块”；历史日志只有在确认同一试块时才映射。
2. 选择材料后，用温度计测量试块实际温度并输入 °C。温度只写入日志供离线分析，不会触发温度补偿，也不会自动填入参考 SOS。
3. 放好试块，点击“自动采集”。停止后日志自动关闭；自动采集中材料记录按钮会禁用，避免一份日志中途换标签。选择“关闭”则自动采集不写实验日志。单次“获取波形”不启用该记录功能。
4. 各材料证书温度—SOS 参考值见 [试块参考值表](../research/specimen-reference-values.md)。程序不在采集时自动插值或改写测量结果。

## 校准与验证

校准向导的“填写试块和参考资料”页新增“保存校准及验证的四通道原始波形”选项，默认勾选。记录直接使用本次输入的试块型号、序列号、温度、参考 SOS；每次独立采集（校准或验证）都有自己的日志文件。如果不希望保存原始波形，可以取消勾选。日志不会影响校准判定或候选 D 激活。

## 文件与内容

点击账号菜单“打开数据文件夹”，进入 `experiments/specimens/`。日志为不覆盖的 `round-*.jsonl`，可按采集时间查看。首条 `start.config` 包含模式、试块身份、温度（校准）、参考声速（校准）、生效 D、采样周期和四通道增益。各 `frame` 条目保存 UTC 时间、当前生效/处理 D、诊断 SOS、lag、相关系数和四个原始通道：`raw_BC`、`raw_BD`、`raw_AC`、`raw_AD`。原始数组的编码为 **base64 / uint16 / little-endian**，与既有患者实验记录一致。结尾的 `stop` 条目说明停止原因。

**大小限制**：每个文件最多 256 MiB，`specimens` 目录下所有 `round-*.jsonl` 共最多 2 GiB，满额会停止记录并在状态栏告警；不自动删除历史文件，也不影响仪器采集。请人工备份和清理不需要的日志。正常使用时不要往这里写入被测者身份信息。

**旧日志处理**：旧版自动采集日志可能已有 `specimen_name`，但没有 `temperature_C`；原始 JSONL 不回写，也不能从波形可靠反推温度。离线分析时可以按原始文件名，在单独的分析表中补充“材料 ID / 实测温度 / 温度来源”；必须有实验记录或操作者确认才补，未知就留空。“塑料试块”不能自动等同于 KSGR-3。

**现有数据**：之前的 `calibration.xml` 仅含轮次统计信息，无法反推四通道原始波形。该功能只对更新后的自动采集写入材料 ID 和温度；历史记录不会自动补齐。

## 实验室验收

用真实设备在 Debug / Release 各确认一次：选择铜块后开始并停止自动采集；再做 KJMK-02 的一小轮校准记录（不要为验证记录功能而激活 D）。核对文件能解析、标签准确、波形可解码、停止后可重新开启；拔线和磁盘空间不足时有提示。计量准确性仍需另外验证。

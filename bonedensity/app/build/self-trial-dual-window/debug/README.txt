双段评分试测版（仅研发验证）

运行本文件夹中的 BoneDensity_DualWindowTrial.exe，标题应包含“双段评分试测版”。
这是独立试测程序，不会替换之前的程序；首次使用需创建测试账号和测试档案。

先测自己：按原来的方法测量，观察是否更容易推进有效值。
完成后移开探头，重新涂好耦合剂、放置探头，再独立测一次。
不必追着3900找位置，不要为了得到这个数而挑选结果。
如果仍然卡住，可以停止，不用一直等；失败记录同样有用。

程序会自动把记录保存到本文件夹的 measurement-experiments 中。
试测后把这个文件夹发回来，并简单说是否更容易测、有没有卡住。
记录含波形，不含姓名；请不要发患者档案XML。

此版本调整A信号质量评分及整轮门槛，SOS计算、D/G条和其他检查不变。
目前仅通过软件回放验证，不代表准确性或不同受试者的效果已经验证。
不要用于临床判断；原来的程序和数据仍保留在原文件夹。

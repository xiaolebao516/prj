# 项目上下文

本文件面向后续Agent，维护项目当前有效事实、关键决策和长期背景，不记录调试流水账。开始任务时先读 `AGENTS.md`、本文件和 `tasks.md`。

## 项目概况

- 项目：超声骨密度仪Windows上位机。
- 技术：Qt 6.5.3、C++17、qmake、MinGW 11.2。
- 主要功能：本地登录、患者档案、串口采集、五轮正式检测、SOS及骨健康结果、检测历史、报表和打印。
- 硬件：Pico/RP2040经USB串口通信，115200波特率。
- 当前开发分支：`codex/feature-complete`。

## 开始工作顺序

1. 读取 `REQUIREMENTS.md`，确认需求状态和产品边界。
2. 读取 `tasks.md`，从最近检查点继续，不重新规划已确认任务。
3. 运行 `git status --short --branch`；有上游时获取远程状态，禁止自动合并、变基或丢弃本地修改。
4. 只在需求已确认、任务和验收标准明确后修改代码。

## 固定构建环境

- 命令行Debug构建只运行：`powershell -ExecutionPolicy Bypass -File .\build-debug.ps1`。
- Qt路径：`D:\Qt\6.5.3\mingw_64`。
- MinGW路径：`D:\Qt\Tools\mingw1120_64`。
- 不得裸跑系统 `qmake`、`mingw32-make` 或 `g++`。系统PATH中的MSYS2 GCC 15会与Qt MinGW 11.2运行库混用，导致 `__glibcxx_assert_fail` 入口点错误。
- Qt Creator可以直接打开 `BoneDensity.pro`；命令行脚本不会修改Qt Creator项目配置。

## 禁止修改区域

未经用户明确批准，不得修改：

- `src/signalprocessor.cpp`、`src/bonehealth.cpp`、`src/utils.cpp` 中的算法。
- 声速计算方法、检测门限、经验参数、相关系数和稳定性判断。
- 串口协议、115200波特率和80 ms采集时序。

校准功能也必须先确认D值含义和公式，不能借校准需求改动上述区域。

## 代码与页面入口

- `src/mainwindow.cpp`：页面状态、串口、检测流程、档案交互和报表入口。文件较大，只做局部修改。
- `include/types.h`：患者和检测记录结构。
- `src/patientstore.cpp`：患者及检测历史XML读写和旧数据迁移。
- `src/accountstore.cpp`：本地账号、认证和损坏管理员恢复。
- `src/reportwidget.cpp`：报表屏幕、PDF和打印共用的绘制逻辑。
- `ui/mainwindow.ui`：主窗口页面和主要控件。
- `resources/resources.qrc`：图片资源注册。

主要页面位于同一个 `QStackedWidget`：登录、主检测、患者新建/选择、档案、患者详情和报表。

## 数据模型与运行时文件

运行时XML位于程序目录：

- `accounts.xml`：账号、角色、启用状态、随机盐和SHA-256哈希。
- `patients.xml`：患者基本资料，一名患者一条。
- `measurements.xml`：检测历史，一名患者可有多条。

关键关系：

- 患者ID是历史关联键，患者详情页ID只读，新建患者时ID可填写。
- 检测记录使用独立UUID，不能按患者ID覆盖旧结果。
- 新检测记录保存当时的患者资料和结果快照，之后修改档案不改变旧报表。
- XML写入使用候选数据和 `QSaveFile`，成功后再更新内存；迁移前保留备份。
- 测试账号和患者数据必须放在隔离目录，不能覆盖真实实验数据。

## 当前用户流程

### 登录与账号

- 默认管理员：`admin / 1`。
- 管理员可创建、启停、重置和删除普通账号；普通账号没有管理入口。
- 管理员凭据必须通过严格Base64和SHA-256长度检查；损坏文件备份后恢复默认管理员。

### 患者与检测

- 未选择患者：显示“建立档案”，开始检测禁用。
- 已选择患者：显示“更换患者”，开始检测启用；选择患者不会自动采集。
- 检测中：禁止更换患者，“开始检测”变为“停止检测”。
- 更换患者会清空未完成轮次、临时数据、趋势和待保存结果，不删除历史。
- 正式检测共五轮。完成后自动追加检测记录，同一患者可以直接再次检测。

### 档案与历史

- 档案一名患者一行，检查日期和SOS来自最新检测记录。
- 普通档案模式可查看历史；导入模式只负责添加或选择患者。
- 选择患者以勾选/选中后点击按钮为主，保留双击快捷方式。
- 历史支持查看报表和删除单条记录；删除患者会确认并同步删除其历史。

### 报表

- 五轮结果保存成功后代码路径直接切换到报表页，不再显示旧完成提示页。
- 报表显示患者快照、检测时间、SOS、T/Z值和程序已有诊断；缺失值显示 `--`。
- 主界面“报表”打开当前患者最新报表；档案历史可以打开指定记录。
- 报表支持导出单页A4 PDF和Windows打印窗口。
- 联系电话暂不录入，打印后由医生手写，等待老师确认。

### 年龄-SOS参考图

- 主界面中间上方按患者性别和检测时年龄显示男童、女童、男性或女性参考背景。
- 0至19岁使用儿童图，20岁及以上使用成人图；多条历史只标记最新一次SOS。
- 新记录优先使用患者年龄和性别快照，旧记录缺失年龄时按生日和检测日期计算。
- 无患者、无历史、资料无效或结果超范围时不绘制虚假测量点，并显示简短状态。
- 四张图坐标范围不同，由 `AgeSosChartWidget` 分别映射；图片始终保持原比例。

# BoneDensity 产品规范

> **Authority:** Agent 按任务精确加载的长期产品事实源。这里只保存产品行为、状态、待办、外部验收边界和证据入口；不定义工作流、当前任务状态、代码配置或人类周报。

## 状态定义

- 草案：关键范围尚未确认，不得直接实施。
- 已确认：范围和预期已确认，可在计划获批后实施。
- 实施中：已进入开发或验证。
- 待验收：软件实现和相应自测已完成，但仍需用户或实验室确认。
- 已验收：用户已认可结果。
- 暂缓：保留需求，当前不实施。

## 产品概况

- 产品：超声骨密度仪 Windows 上位机。
- 主要能力：本地账号、患者档案、串口采集、五轮正式检测、SOS 与骨健康结果、检测历史、年龄-SOS 图、报表/PDF/打印和标准试块校准。
- 当前患者正式 SOS 使用 B 通道；A 通道硬件偏差尚未通过标准试块校准解决。
- 校准候选 D 在独立验证和操作者确认前不得影响患者测量。

## REQ-001：本地账号管理

状态：已验收

目标是在不引入数据库和服务器的前提下支持实验室多人使用。

- 内置管理员为 admin / 1。
- 管理员可以创建、启用、停用、删除和重置普通账号；普通账号不能管理账号。
- 账号保存在本地 accounts.xml，密码以随机盐和 SHA-256 哈希保存，不保存明文。
- 管理员凭据读取必须严格校验 Base64 和 SHA-256 长度，正常账号文件不得被误重置。
- 缺少有效管理员凭据或账号文件损坏时，先备份异常文件，再恢复默认管理员；恢复失败必须明确提示。

已知部署风险：默认口令简单，盐化 SHA-256 不是慢速密码派生函数，且本地运行数据未加密。改善认证策略属于后续需确认的安全需求。

## REQ-002：患者档案与多次检测记录分离

状态：已验收

- 患者基本资料一人一条，检测记录一人可有多条。
- 患者资料保存在 patients.xml，检测历史保存在 measurements.xml。
- 每条检测记录保存实际产生的时间、SOS、T/Z 值、诊断和患者资料快照；修改档案不得改变旧报表。
- 患者 ID 是历史关联键；详情页 ID 只读，新建患者时允许填写 ID，检测记录使用独立 UUID。
- 支持查看和删除单条历史；删除患者时需确认并同步删除其历史。
- 尽量兼容旧 patients.xml；迁移前保留备份，失败不得损坏源文件或产生部分内存状态。

## REQ-003：患者选择与检测操作分离

状态：已验收

- 未选择患者时显示“建立档案”，开始检测不可用。
- 已选择患者时显示“更换患者”，开始检测可用；建立或选择患者都不得自动开始采集。
- 检测中禁止更换患者，“开始检测”切换为“停止检测”。
- 更换患者时清空未完成轮次、趋势和临时结果，但不得删除已保存历史。

## REQ-004：检测完成与档案交互

状态：待验收

- 五轮检测完成后自动追加一条结果，不再要求额外保存。
- 同一患者可以直接再次检测，每次形成独立历史记录。
- 档案列表一名患者一行，展示最近检测日期和 SOS；历次结果从历史入口查看。
- 导入患者以选中后点击“选择患者”为主要方式，同时保留双击快捷方式。

待现场确认：真实设备完成五轮后的自动保存、同患者再次测量和历史追加。

## REQ-005：USB 断开稳定性与界面中文化

状态：待验收

- USB 拔出后只提示一次，停止采集、清理接收状态并恢复为未连接，不得连续弹窗或闪退。
- 错误提示使用医生可理解的中文，说明可能原因和处理建议。
- 连接、获取波形和自动采集等操作使用中文。

待现场确认：真实 USB 热拔插、不同设备驱动异常和重连流程。

## REQ-006：主界面响应式布局

状态：已验收

- 默认窗口、最大化和常见缩放状态下，波形、趋势、患者信息、结果和示意图不得遮挡。
- “获取波形”和“自动采集”含义明确，患者操作按钮排列清晰。
- 导入模式只负责添加或选择患者，不显示检测历史入口。

## REQ-007：样式化检测报表

状态：待验收

- 五轮结果保存成功后直接进入正式报表页，不显示旧完成提示页。
- 报表显示患者快照、检测时间、SOS、T/Z 值和程序实际已有的诊断；缺失字段显示 --。
- 历史记录可打开任意一次报表，后续档案修改不得改变旧报表。
- 主界面“报表”打开当前患者最新报表，档案历史入口打开指定记录。
- 支持导出单页 A4 PDF 和调用 Windows 打印窗口。
- 联系电话暂不录入软件，由医生打印后手写；是否增加配置需另行确认。
- 报表页面、旧记录兼容、PDF 渲染和系统打印窗口已有软件证据。
- 普通 PDF 不得描述为 DICOM 或医院信息系统集成。

待现场确认：真实设备五轮完成后的自动跳转，以及实体打印机的 A4 边距、驱动缩放和纸面清晰度。

## REQ-008：年龄-SOS 参考图

状态：待验收

- 横轴为年龄，纵轴为 SOS；按患者性别和年龄选择男童、女童、男性或女性参考背景。
- 0 至 19 岁使用儿童图，20 岁及以上使用成人图；范围以现有四张素材为准。
- 多条历史只标记最新一次结果；新记录优先使用年龄和性别快照，旧记录缺失年龄时按生日和检测日期计算。
- 未选择患者时显示中性空状态；已选择患者但没有结果时显示对应年龄/性别参考背景。无结果、资料无效或超出素材范围时均不得绘制虚假点，并显示简短状态。
- 默认窗口、最大化和缩放后图片不得变形或遮挡。
- 四张参考图的坐标范围不同，AgeSosChartWidget 必须分别映射，不能用单一坐标范围套用所有素材。
- 匿名边界数据位于 testdata/age-sos-reference/，覆盖四类背景、19/20 岁边界、最新记录、旧记录、无记录和超范围结果。
- 参考图仅为课题组现有素材呈现，不构成新增医学诊断标准。

软件演示已完成，仍待用户验收。

## REQ-009：标准试块探头校准

状态：软件实现与自测完成，待实验室验收

目标是根据可追溯标准试块在指定温度下的参考声速和软件实测声速，生成并验证探头 C-D 有效基线 D 的候选值。失败或未激活时继续使用原参数，并始终保留默认值 7.84 mm。

- 校准向导覆盖说明、资料、6 次校准采集、重新放置、6 次独立验证和结果确认；必需步骤不得跳过。
- 正式模式记录探头、试块、证书编号及参考温度/SOS；试块温度由操作者用外部温度计测量并输入。软件检查完整性和数值范围，但不验证证书真实性。
- 页面提示操作者核对试块与证书、通过签发机构渠道追溯证书，并按证书读取当前温度对应的标准 SOS。
- 输入温度与证书参考点的偏差不得超过 ±1 C；超出时拒绝继续。
- 没有可追溯证书时允许研发演示，但候选 D 永远不得激活。
- 校准与患者检测使用相同底层滤波、到达时间、相关峰和 SOS 计算，不修改患者算法、门限、串口协议或采集时序。
- 校准不使用人体姿态门限。B 通道生成候选 D，A 通道只显示稳定性和一致性诊断。
- 每次独立测量累计 30 个有效帧；6 次独立测量生成候选 D。取下探头、清洁并重新涂同一种耦合剂后，再做 6 次独立验证。
- 候选公式：D候选 = D当前 × 试块参考SOS / 校准阶段B通道平均SOS。
- 候选 D 在独立验证和用户确认前不得影响患者测量。
- 工程阈值：B 通道平均 SOS 相对误差不超过 ±2%，6 次结果变异系数不超过 1%，且候选与原参数搜索不得发生明显峰值跳变。
- 页面必须说明这些阈值参考 YY/T 0774-2019 产品性能要求，不是标准规定的内部 D 校准方法，也不等同于计量校准结论。
- 软件提示均匀覆盖耦合剂、排除气泡、保持方向和压力一致，但不能自动验证耦合剂用量、温度真实性或人工操作。
- 6 次校准与 6 次验证应逐次显示温度、有效帧进度、B 通道结果和 A 通道诊断。
- 无串口时允许查看说明、资料、参数和历史，但开始采集时必须给出明确提示。
- 正式模式验证通过并由操作者确认后才能激活；失败保持原 D。
- 保存当前、上一和只读默认 D（7.84 mm）及校准历史；写入失败不得部分生效，支持恢复上一值和默认值。
- 校准历史必须可查看时间、操作者、试块、证书编号、原 D、候选 D、验证结果和最终状态。
- 校准历史和结果只能使用“工程验证通过/未通过”，不得显示“国家标准校准合格”等误导性表述。

证据入口：

- test-calibration.ps1：校准公式、边界、候选隔离、权限、持久化、恢复和界面专项测试。
- docs/probe_calibration_references.md：国家药监局器审中心官方 PDF、YY/T 0774-2019 第 3.6、4.2 和 5.3 条及解释边界。
- build-debug.ps1：固定 Qt 6.5.3/MinGW 11.2 Debug 构建复现入口。

未验证且必须留给实验室：

- 合格试块、外部温度计和真实探头下的 12 次采集；
- 真实温度、耦合质量和重新放置重复性；
- 候选 D 的实际精度以及对患者测量的影响。

## REQ-010：整机数据迁移

状态：已确认，尚未实施

- 审计全部运行时数据、版本、备份、恢复和资源依赖。
- 迁移覆盖账号、患者、检测历史、校准配置及相应完整性信息。

## 已知风险与候选事项

- 构建脚本硬编码本机 Qt/MinGW 路径，换电脑需相同布局或另行批准改进。
- src/mainwindow.cpp 仍是维护热点，不得为整洁进行无关重构。
- 运行数据位于程序目录且没有整机导入/导出；REQ-010 尚未实施。
- 默认管理员口令和密码派生策略存在部署安全风险。
- 年龄-SOS 图完全依赖现有位图素材。
- 报表实体出纸、USB 行为、真实五轮流程和试块校准仍有外部验收边界。
- 历史报表一键清理仅是候选需求；未确认保留规则前不得实施。
- 为非校准功能补充自动化测试、改善工具链路径探测和降低 mainwindow.cpp 耦合均需先形成批准需求。
